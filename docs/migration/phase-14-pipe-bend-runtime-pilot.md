# Phase 14 - Pipe+Bend runtime pilot export

## Status

This phase is productive runtime/export capability.

It expands the explicit runtime pilot from pipe-only to pipe+bend RVM subset export.

It generates real RVM subset bytes and audit metadata for the currently loaded new-core/BM_CII pipeline while preserving the existing production export path.

## User-facing behavior

The advanced panel remains:

```text
New-Core Pilot Export
```

It now exposes both explicit pilot actions:

```text
Generate CYLINDER/code8 Pilot RVM
Generate Pipe+Bend Pilot RVM
```

The Pipe+Bend action generates:

```text
BM_CII_pipe_bend_runtime_pilot.rvm
BM_CII_pipe_bend_runtime_pilot.audit.json
```

The action is explicit only and never runs on app initialization.

## Included primitives

The Phase 14 runtime pilot includes only:

```text
19 CYLINDER/code8 straight pipes
7 TORUS/code4 bends
```

`TORUS/code4` becomes runtime-pilot artifact-ready only. It is not production-writer-ready.

## Excluded families

The runtime artifact still excludes:

```text
8 FLANGE_CYLINDER/code8 flange bodies
6 valves
12 supports
```

Flanges remain excluded from runtime artifact generation in this phase.

Valves remain blocked.

Supports remain deferred.

ATT and GLB remain separate boundaries and are not generated by this pilot.

Full RVM readiness remains false.

## Architecture boundaries

`PlantModelGraph.v1` remains the engineering source-of-truth.

Managed/staged JSON child identity remains source-import evidence only.

`ElementRvmLedger.v1` remains downstream trace/readiness evidence only.

`RvmExportModel.v1` remains adapter/dry-run/test-byte/runtime-pilot boundary.

No default runtime switch is enabled.

No unsupported primitive may be silently downgraded.

No fallback cube, box, sphere, pyramid, valve placeholder, or support placeholder is introduced.

## Old export path

This phase does not modify production writer internals.
