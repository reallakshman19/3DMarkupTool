# Phase 13 - Browser CYLINDER/code8 pilot export

## Status

This phase exposes the Phase 12 runtime/export pilot through an advanced explicit browser action.

It does not replace normal export and does not enable a default runtime switch.

## User-facing behavior

The managed-stage UI adds an advanced panel labelled:

```text
New-Core Pilot Export
```

The panel contains an explicit button:

```text
Generate CYLINDER/code8 Pilot RVM
```

The panel warns:

```text
Pilot export only:
- straight pipe CYLINDER/code8 subset
- bends excluded
- flanges excluded
- valves blocked
- supports deferred
- old production export unchanged
```

The pilot never runs automatically on load. The user must explicitly click the pilot button.

## Generated downloads

After explicit click, the browser prepares exactly two pilot downloads:

```text
BM_CII_cylinder_code8_runtime_pilot.rvm
BM_CII_cylinder_code8_runtime_pilot.audit.json
```

Object URLs are created only inside the explicit pilot download action and are revoked immediately after click.

## Scope

This phase generates only straight-pipe `CYLINDER/code8` subset bytes.

Unsupported families remain excluded from runtime artifact generation:

- bends remain excluded;
- flanges remain excluded;
- valves remain blocked;
- supports remain deferred;
- ATT remains separate and is not generated by this pilot;
- GLB remains separate and is not generated by this pilot.

TORUS/code4 remains test-byte proof only. `FLANGE_CYLINDER/code8` remains Phase 11C-B test-byte proof only.

Full RVM readiness remains false.

## Architecture boundaries

`PlantModelGraph.v1` remains the engineering source-of-truth.

Managed/staged JSON child identity remains source-import evidence only.

`ElementRvmLedger.v1` remains downstream trace/readiness evidence only.

`RvmExportModel.v1` remains the adapter/dry-run/test-byte/runtime-pilot/browser-pilot boundary.
