# Phase 15 - Pipe+Bend+Flange runtime pilot package with ATT subset

## Status

This phase is productive runtime/export capability.

It extends pilot output from pipe+bend to pipe+bend+flange and adds a matching ATT subset.

It generates real RVM subset bytes and deterministic pilot ATT text for generated pilot elements.

## User-facing behavior

The advanced panel remains:

```text
New-Core Pilot Export
```

It now exposes three explicit pilot actions:

```text
Generate CYLINDER/code8 Pilot RVM
Generate Pipe+Bend Pilot RVM
Generate Pipe+Bend+Flange Pilot Package
```

The package action generates:

```text
BM_CII_pipe_bend_flange_runtime_pilot.rvm
BM_CII_pipe_bend_flange_runtime_pilot.att
BM_CII_pipe_bend_flange_runtime_pilot.audit.json
```

The action is explicit only and never runs on app initialization.

## Included primitives

The Phase 15 runtime pilot package includes:

```text
19 CYLINDER/code8 straight pipes
7 TORUS/code4 bends
8 FLANGE_CYLINDER/code8 flange bodies
```

`TORUS/code4` and `FLANGE_CYLINDER/code8` become runtime-pilot artifact-ready only.

They are not production-writer-ready.

## ATT subset

The package includes one ATT row per generated RVM primitive.

Expected BM_CII ATT subset:

```text
34 ATT rows
```

The pilot ATT format is stamped:

```text
# ATT Pilot Export
# schema: PipeBendFlangeRuntimePilotAtt.v1
# scope: pipe-bend-flange-subset
```

Rows use stable fields and do not invent engineering tags:

```text
elementId|sourceItemId|sourcePrimitiveId|exportPrimitiveId|primitiveKind|primitiveCode|family|catalogueItemId|tag|name|runtimePilotStatus|runtimePilotScope
```

Missing optional tag/name values remain empty strings.

## Excluded families

The runtime package still excludes:

```text
6 valves
12 supports
```

Valves remain blocked.

Supports remain deferred.

GLB remains separate and is not generated by this pilot.

Full RVM readiness remains false.

## Architecture boundaries

`PlantModelGraph.v1` remains the engineering source-of-truth.

Managed/staged JSON child identity remains source-import evidence only.

`ElementRvmLedger.v1` remains downstream trace/readiness evidence only.

`RvmExportModel.v1` remains adapter/dry-run/test-byte/runtime-pilot boundary.

`AttExportModel.v1` remains the attribute export boundary.

No default runtime switch is enabled.

No unsupported primitive is silently downgraded.

No fallback cube, box, sphere, pyramid, valve placeholder, or support placeholder is introduced.
